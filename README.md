# Шырақ (Shyraq)

2D-платформер для мобильных (landscape) о девочке **Ай** и фонаре её деда.
Ночная казахская степь, легенда о Темірқазық, Ақбозат и Көкбозат и семи разбойниках Жеті қарақшы.

Курс Game Development Fundamentals (Narxoz). Автор: Алмасбек.

## Идея
Разбойники сорвали звёзды, небо погасло, из темноты вышли духи. Ай светит фонарём:
- **луч** (удержание, наводится стиком) открывает тайные тропы и замораживает духов;
- **Жарқыл** (FIRE) — снаряд света;
- **масло** тратится, свет надо беречь.

Цель уровня — собрать все звёзды, тогда открываются ворота.
Сцены: Main Menu → Level 1 «Дала» → Level 2 «Сай» → Level 3 «Темірқазық» (босс) → Win.

Подробно: [`KOK_concept_locked.md`](KOK_concept_locked.md).

## Управление
| Действие | Мобильный | Клавиатура (тест) |
|---|---|---|
| Ходьба | стик | A / D, стрелки |
| Прыжок (двойной) | JUMP | Space |
| Луч | LIGHT (удержание) | E / Left Shift |
| Жарқыл | FIRE | J / X |
| Пауза | кнопка паузы (справа вверху) | — |

## Как открыть
1. Unity **6000.6.9f1** (Unity 6), шаблон Universal 2D.
2. Unity Hub → Add → папка проекта.
3. Стартовая сцена — `Assets/Scenes/MainMenu.unity` (первая в Build Settings).
